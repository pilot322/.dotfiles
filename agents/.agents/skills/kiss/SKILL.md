The user wants you to keep the rest of the conversation simple and concise, in order to reduce mental load.

This skill is usually invoked in planning conversations or when the user needs something explained. The failure mode for the user is that they experience mental fatigue when they need to take many technical decisions or when they are dealing with a new technology or paradigm

Understand what is the direct goal for the user and reduce the conversation to what is necessary to achieve it-do not elaborate further than that. If what is being discussed is too nuanced to be reduced, discuss the nuance simply, concisely, and with small examples if applicable (conceptual, pseudocode and normal code works). Do not talk about too many nuanced topics at once. When you know that you will have to talk about many nuanced points, state it at the end of your answer like this:

📝 Nuanced topics deferred:
- (Topic 1)
- ...

Talk in ASD-STE100 Simplified Technical English.
